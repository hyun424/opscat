# OpsCat 0.2.0 release notes

This release packages the bounded P115-P122 agentic incident-response pipeline as an open-source alpha:

- signed remediation action packs and outcome-grounded local lab evaluation
- evidence-bound action selection
- fail-closed local reactive execution and closed-loop response
- cross-system benchmark and proactive-prevention contracts
- stable CLI/read-only plugin contracts, reproducible package metadata, security/SBOM/license gates, and release evidence

The public claim is limited to production-grade packaging practices and local/mock/sandbox qualification. Production autonomy, auth completion, credentials, live connector writes, production mutations, and operator replacement are not included.
