# P138-001 - Exact contracts, paths, and counters

## Scope

Write failing tests, then define the exact-key, canonical, self-hashed P138
config, `p138.supervisor_phase.v1`, ledger, checkpoint, heartbeat, readiness,
termination, case, resource, and release-evidence contracts. Define the P136
`p136.cycle_outcome_intent.v1` and `p136.cycle_completion.v1` contracts at one
deterministic outcome path and the relative/disjoint topology required by the
approved Third Mandatory Amendment.

## Acceptance

- Contract tests first reject missing/unknown keys, invalid hashes/timestamps,
  nullable fields after their owning phase, booleans in integer fields,
  negatives, unbounded limits, and stamped measurements.
- Paths are exact relative, disjoint, and non-overlapping, including
  `cycle_outcome_dir`, P138 phase/ledger/state paths, publisher
  state/intent/lease paths, P137 state, and fixed handoff
  `handoff/p137/p136_handoff_bundle.v1.json`.
- Runtime inputs require complete canonical P136/P137 configs and qualified
  evidence; hash-only references fail closed.
- `forbidden_authority` is exact set-equal to the shared 15-key P136/P137 tuple
  in the roadmap, with integer zero for every value. Stale auth/notification/
  action aliases, missing/extra keys, booleans, negatives, and nonzero values
  fail in every schema and aggregate.
- `runtime_activity` and `evaluator_activity` use exactly the closed key sets in
  the roadmap; aliases and dependency-internal counters fail closed.
- `p138.supervisor_phase.v1` binds all phase, predecessor, P136, publisher,
  P137, exact-counter, timestamp, and hash fields, with nullability only before
  the owning phase.
- `p136.cycle_outcome_intent.v1` binds config/cycle/receipt, starting checkpoint
  hash, complete resulting checkpoint/hash, promotion count and exact ordered
  sequence/hash lists including empty, creation time, file/parent fsync
  assertions, and intent hash. `p136.cycle_completion.v1` preserves those
  fields and adds the intent hash, committed checkpoint hash, completion time,
  and completion hash.
- Targeted contract tests, Ruff, and Mypy pass before P138-002 starts.
