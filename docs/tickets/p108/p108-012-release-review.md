# P108-012 - Release Evidence and Independent Review

Aggregate the six P108 release gates, exact fixture identity, benchmark hashes,
authority counters, per-family metrics, recommendation version manifests, and
fresh independent review into fail-closed release evidence.

The review must use `p108.independent_review.v1`, be producer-independent and
fresh, and bind the ledger head, release evidence, fixture matrix, holdout,
promotion, recommendation, authority scan, docs scan, and release-profile
output hashes.

Done when independent code, architecture/safety, and adversarial verification
all pass and P108 remains explicitly offline and unapplied.
