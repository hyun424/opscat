# P129 Adversarial Test Specification

Implementation is pending. This planning spec requires no source/test edits,
release publication, credentials, staging access, production access, or
mutation.

## Required Rejections

- Hidden credential requirement, production-readiness claim, enterprise support
  claim, missing security disclosure path, unknown license, missing SBOM,
  unsigned or unverified artifact where status is claimed, undocumented
  compatibility break, self-reviewed release, and nonzero authority counter.

## Required Checks

- Governance and contribution policy are explicit.
- Security intake and vulnerability severity gates are defined.
- Versioning and compatibility rules are documented.
- Artifact provenance, SBOM, license inventory, and limitations are required.

## Named RED Cases

- `oss_hidden_credential_requirement`
- `oss_production_ready_claim`
- `oss_missing_security_policy`
- `oss_unknown_license`
- `oss_missing_sbom`
- `oss_untraced_artifact`
- `oss_self_reviewed_release`
- `oss_nonzero_authority_counter`
