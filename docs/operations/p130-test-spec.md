# P130 Adversarial Test Specification

Implementation is pending. This planning spec requires no source/test edits,
public launch, credentials, staging access, production access, or mutation.

## Required Rejections

- Production-ready claim, production autonomy claim, real staging/production
  mutation, credential requirement, live connector proof, auth completion
  claim, operator-replacement claim, missing limitation, missing withdrawal
  path, unsupported support promise, and nonzero authority counter.

## Required Checks

- Beta entry criteria map to evidence.
- Public claims map to evidence or limitations.
- Known risks have owners and mitigations.
- Feedback intake requires no credentials or production access.
- Exit, rollback, and claim-withdrawal gates are defined.

## Named RED Cases

- `beta_production_ready_claim`
- `beta_auth_complete_claim`
- `beta_requires_credentials`
- `beta_live_connector_proof_claim`
- `beta_missing_limitation`
- `beta_missing_risk_owner`
- `beta_missing_withdrawal_path`
- `beta_nonzero_authority_counter`
