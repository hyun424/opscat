# P156 Test Specification

1. Reject stale P155 evidence, malformed model proposals, invalid citations,
   unsafe actions, and truth leakage.
2. Arbitrate deterministic and model proposals using evidence-only rules.
3. Measure top-1 accuracy, abstention accuracy, override precision, citation
   validity, and unsafe proposal rejection.
4. Prove the model has zero action authority and bind final artifacts.
