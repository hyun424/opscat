# P134-001 Contract and Level Separation

Status: complete

Define the strict contract core, five closed `OA*` observation levels, OA0/OA1 P134
qualification boundary, closed allowlists, exact integer budgets, forbidden
field/value scan, exact-zero P121 action authority, and self-hash validation.

Acceptance: malformed, authority-bearing, credential-shaped, network-shaped,
or optimistic contracts fail closed before any proposal evaluation. Observation
level names must remain distinct from action-authority level names.
