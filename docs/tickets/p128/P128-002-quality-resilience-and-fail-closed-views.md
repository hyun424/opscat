# P128-002: quality, resilience, and fail-closed views

## Goal

Plan views for P124 quality, P125 resilience, and P127 fail-closed evidence.

## Contract

Show denominators, failures, cost/restart context, blocked actions, and
operator-visible fail-closed reasons.

## Acceptance

Future UX exposes evidence limits instead of hiding failures.

## Stop Rules

Stop if views omit denominators, failure cases, or fail-closed reasons.
