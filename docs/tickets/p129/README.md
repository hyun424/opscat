# P129 tickets

P129 defines the OSS distribution maturity planning phase. Implementation is
pending.

1. `[planned] P129-001` - governance, maintainership, and contribution policy
2. `[planned] P129-002` - security intake and release-blocking policy
3. `[planned] P129-003` - versioning, compatibility, and migration policy
4. `[planned] P129-004` - artifact provenance, SBOM, licenses, and distribution
5. `[planned] P129-005` - verification handoff and beta readiness gate

Auth is deferred, credentials are out of scope, production/staging mutation is
forbidden, and authority counters remain exactly zero.

`docs/operations/p129-test-spec.md`,
`docs/operations/p129-plan-review.md`, and
`docs/operations/p129-verification-handoff.md`.
