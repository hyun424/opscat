# P109-000 Source Manifest and Provenance

Define immutable RCAEval and MicroRemed source revisions, canonical URLs,
licenses, expected paths, byte limits, and checksums. No moving branch may be
release evidence.

Implement and document `p109.source_manifest.v1`,
`p109.source_artifact.v1`, and `p109.provenance_hashes.v1` exactly as specified
in the roadmap. Unknown major versions and incomplete hash chains fail closed.
