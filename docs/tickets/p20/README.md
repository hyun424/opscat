# P20 Tickets — Closed-loop Agentic Incident Response

P20 connects observation, LLM-shaped judgment, missing evidence collection, revised judgment, action proposal, simulation, and final routing into one audited local/mock agent loop.

Boundary: no auth, no production mutation, no default external model calls, no action execution, no unattended production-operation claim.

Tickets:

- P20-001 Loop state and trace schema
- P20-002 Initial judgment adapter
- P20-003 Missing evidence executor
- P20-004 Revised judgment pass
- P20-005 Action proposal and policy routing
- P20-006 Simulation before approval
- P20-007 Loop CLI and verification smoke
- P20-008 Release evidence
