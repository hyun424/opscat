# P135-005 - Fixed evaluation runner

## Deliverable

Create the five canonical provider fixtures, adversarial fixtures, profile, and
bounded 30-case runner.

## Acceptance

- Fixed denominator 30/30.
- Every provider succeeds once; duplicate is deterministic.
- Path, parser, provenance, tamper, and authority failures are represented.
- Runtime resource and authority ledgers are emitted.
- Production/staging identifiers are untrusted data; live-proof claims fail.
