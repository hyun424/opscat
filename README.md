# OpsCat

AI on-call agent for incident investigation and safe response automation.

## MVP

OpsCat receives an alert, gathers incident context, investigates likely causes, proposes a safe action, requests approval when needed, executes approved actions, and verifies recovery.

Initial integration target:

- Mock alert engine first
- Sentry
- GitHub
- Slack

See `.omx/plans/opscat-mvp-plan.md` for the MVP plan.
